SN. PRIVATE — SETUP GUIDE FOR SHUBHAM
10-MINUTE, NO-CODE SETUP

Turn on real sign-in, ratings, comments & forum

Right now your site runs in demo mode — everything works, but data saves only in each person's own browser. Follow these steps once to switch it to live mode, where accounts, ratings, comments and the forum are real and shared across everyone. You won't write any code — just copy, paste, and click.

THE BIG PICTURE

You need two free things:

1Firebase — Google's free service. It handles the sign-ins and stores all the ratings/comments/forum posts.
2GitHub Pages — free hosting so anyone can visit your site at a real web address.
STEP 1

Create a Firebase project

1. Go to console.firebase.google.com and sign in with your Google account.

2. Click “Add project”, name it (e.g. shubham-portfolio), and click through — you can turn Google Analytics off.

3. When it's ready, click Continue.

STEP 2

Get your config keys

1. On the project home, click the </> (web) icon to “Add a web app.”

2. Give it a nickname, click Register app.

3. Firebase shows a block of code with apiKey, authDomain, etc. Copy that whole config object.

4. Send it to me, or paste it yourself in Step 5. That's the only “code” involved — a copy-paste.

STEP 3

Turn on the sign-in methods

In the left menu: Build → Authentication → Get started. Then under Sign-in method, enable each of these (just flip them on and Save):

→Email/Password — also toggle on “Email link (passwordless)” for your magic-link option.
→Google — one click to enable.
→GitHub — needs a free “OAuth app” on GitHub (it gives you a Client ID + secret to paste in). I'll walk you through this one if you want it; it's the only slightly fiddly method.
STEP 4

Create the database

1. Left menu: Build → Firestore Database → Create database.

2. Pick a location close to your users (e.g. asia-south1 for India), start in production mode.

3. Go to the Rules tab and paste the rules below (they let anyone read, only signed-in people write, and only you delete). Then Publish:

rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /{doc=**} {
      allow read: if true;
      allow create, update: if request.auth != null;
      allow delete: if request.auth != null;
    }
  }
}

(This is a simple, safe starting point. Once you're live I can tighten it so only you can delete others' posts.)

STEP 5

Paste the keys in (or send them to me)

Open the file community.js. Right at the top you'll see this — just fill in the values from Step 2:

window.SN_FIREBASE = {
  apiKey: "PASTE_HERE",
  authDomain: "PASTE_HERE",
  projectId: "PASTE_HERE",
  appId: "PASTE_HERE",
  storageBucket: "PASTE_HERE",
  messagingSenderId: "PASTE_HERE"
};

The moment real keys are in there, the whole site flips from demo to live automatically. Easiest option: just send me the config block and I'll paste it in for you.

STEP 6

Put it online with GitHub Pages

1. Create a free account at github.com.

2. Make a new repository (name it e.g. portfolio), and upload all the site files.

3. In the repo: Settings → Pages, set the source to your main branch, Save.

4. In a minute GitHub gives you a live link like yourname.github.io/portfolio.

5. Rename your main file to index.html so it opens by default (I can do this for you at export time).

6. Last thing: back in Firebase → Authentication → Settings → Authorized domains, add your github.io address so Google/GitHub sign-in works there.

That's it — you're live. 🎉
